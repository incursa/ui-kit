# Support

Use this repository's public issues for reproducible bugs, focused change proposals, and documentation problems.

## Public Support Scope

Maintainers can usually help with:

- documented setup and validation problems
- reproducible bugs in supported package versions
- focused questions about public APIs or documented behavior
- documentation gaps
- consumer guidance for choosing compiled CSS, SCSS, the JS helper, or Web Components

Maintainers usually cannot provide:

- private consulting through public issues
- debugging of private codebases
- support for unsupported forks or modified builds
- help with secrets, credentials, or private infrastructure in public threads

## Security

Do not report vulnerabilities or secrets in public issues. Follow [`SECURITY.md`](SECURITY.md).
