# UI Kit Spec Suite

This folder contains the current Spec Trace pass for the Incursa UI kit.

The suite is organized by shared foundations first, then by stable UI concern rather than by page example:

- [SPEC-UIK-STD](SPEC-UIK-STD.md) - public surface standards
- [SPEC-UIK-TOK](SPEC-UIK-TOK.md) - theme tokens and value contract
- [SPEC-UIK-A11Y](SPEC-UIK-A11Y.md) - accessibility baseline and semantic behavior
- [SPEC-UIK-CNV](SPEC-UIK-CNV.md) - control surface conventions and shared modifiers
- [SPEC-UIK-LAY](SPEC-UIK-LAY.md) - layout primitives and shell
- [SPEC-UIK-BTN](SPEC-UIK-BTN.md) - button and action controls
- [SPEC-UIK-TXT](SPEC-UIK-TXT.md) - typography and text helpers
- [SPEC-UIK-FRM](SPEC-UIK-FRM.md) - form layout and grouping
- [SPEC-UIK-INP](SPEC-UIK-INP.md) - editable form controls
- [SPEC-UIK-SEL](SPEC-UIK-SEL.md) - select controls
- [SPEC-UIK-GRP](SPEC-UIK-GRP.md) - input group composition
- [SPEC-UIK-RO](SPEC-UIK-RO.md) - read-only field display
- [SPEC-UIK-CHO](SPEC-UIK-CHO.md) - binary choice controls
- [SPEC-UIK-VAL](SPEC-UIK-VAL.md) - validation and error feedback
- [SPEC-UIK-FLT](SPEC-UIK-FLT.md) - filter and bulk action bars
- [SPEC-UIK-CARD](SPEC-UIK-CARD.md) - card and section surfaces
- [SPEC-UIK-LIST](SPEC-UIK-LIST.md) - list and collection rows
- [SPEC-UIK-TBL](SPEC-UIK-TBL.md) - tables and data grids
- [SPEC-UIK-UTL](SPEC-UIK-UTL.md) - public utility and helper classes
- [SPEC-UIK-NAV](SPEC-UIK-NAV.md) - navigation shell and menus
- [SPEC-UIK-FDBK](SPEC-UIK-FDBK.md) - feedback and operational states
- [SPEC-UIK-OVL](SPEC-UIK-OVL.md) - overlays and disclosures
- [SPEC-UIK-MET](SPEC-UIK-MET.md) - metrics and status surfaces
- [SPEC-UIK-FILE](SPEC-UIK-FILE.md) - file review surfaces
- [SPEC-UIK-INT](SPEC-UIK-INT.md) - interaction helper contract

Open issues and follow-up questions live in [REQUIREMENT-GAPS](REQUIREMENT-GAPS.md).
